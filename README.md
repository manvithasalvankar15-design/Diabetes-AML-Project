# Diabetes Prediction using Machine Learning

## Project Overview
This project predicts whether a person is likely to have diabetes
using machine learning algorithms.

## Dataset
Pima Indians Diabetes Dataset

## Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Files
- Diabities Prediction.ipynb
- diabetes.csv
